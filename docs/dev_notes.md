# Driver Drowsiness & Distraction Detection - Project Plan

## Phase 1: Research & Data Collection
- Study existing drowsiness detection approaches
- Collect and preprocess facial landmark datasets
- Evaluate MediaPipe vs Dlib for landmark detection

## Phase 2: Model Development  
- Implement EAR (Eye Aspect Ratio) calculation
- Implement MAR (Mouth Aspect Ratio) for yawn detection
- Train CNN model for distraction classification

## Phase 3: Integration
- Build real-time detection pipeline
- Integrate frontend webcam feed
- Add alert system for drowsy drivers
